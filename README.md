# dataeng_lab3

Репозиторий для лабораторной/домашней работы по инженерии данных.

## Технический каркас

Подготовлена минимальная структура для выполнения задания:

- `infra/` — запуск объектного хранилища (RustFS) через Docker Compose;
- `configs/` — шаблон переменных окружения пайплайна;
- `src/mapreduce/` — место под собственную реализацию MapReduce;
- `src/sql/` — SQL-шаблоны для DuckDB и сверки результатов;
- `scripts/` — обвязка для загрузки данных, запусков и профилирования;
- `data/` — каталоги для входных/промежуточных/итоговых данных;
- `profiling/` — результаты замеров времени и памяти;
- `reports/` — материалы отчёта.

> В этом коммите добавлен только каркас. Реализацию расчётов и аналитики нужно выполнить отдельно по своему варианту.
